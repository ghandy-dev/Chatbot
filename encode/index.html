Commands

Encode

Description Encode text transforming it to a different format.
Command encode
Aliases
Cooldown 5 seconds
Admin only? ✘
Usage
encode <encoder> <input>

Ciphers/Encoders:
- caesar
- rot13
- base64

Encode text using the caesar cipher. Optionally specify a shift value.
encode ceaser Kappa 123
Encode text using the caesar cipher, and shift/rotate the letters by 5 places.
encode ceaser 5 This is a cool secret message B)

Encode text using the caeser cipher with a 13 letter shift, re-applying this again to the encoded text decodes it instead.
encode rot13 Hello World!

Encode text to base64.
encode base64 forsen
