Commands

Text to Ascii

Description Transform text to ascii text.
Command texttoascii
Aliases tta
Cooldown 15 seconds
Admin only? ✘
Usage
texttoascii <text>

texttoascii KAPPA

Optional arguments:

greyscale:
- lightness (default)
- luminance
- average
- max

dithering:
- false (default)
- true

invert:
- false (default)
- true

monospace:
- false
- true (default)

texttoascii <optional arg> ... <text>
texttoascii greyscale:average dithering:true invert:false monospace:true JEBAITED
