Commands

FaceIt

Description Get recent match stats, or recent history of wins and losses for games played on FaceIt for CS2.
Command faceit
Aliases
Cooldown 20 seconds
Admin only? ✘
Usage
Get last game stats (can't get live game info):
faceit <player name>
faceit FrozenBag

Get stats for a player:
faceit stats <player name>
faceit stats FrozenBag

Get a players recent win/loss history:
faceit history <player name>
faceit history FrozenBag
